# Selah-space

A calm, private place to write out your feelings and find reassurance.

Selah Space is a journaling app for anyone who loves documenting how they feel or needs a gentle word when things get heavy. It is peaceful by design, with an optional faith layer for those who want it. Faith is never required, and the app is for everyone.

## Features

- **Sign-in:** your own account, so your entries stay yours
- **Journal entries:** write and save how you feel, any time
- **Streaks:** build a steady journaling habit
- **Reminders:** gentle nudges to take a moment for yourself
- **Progress tracking:** look back and see how far you've come
- **Reassurance:** encouragement when you need it
- **Optional faith layer:** turn on faith-based content if it speaks to you

## Design Goals

- Clean, uncluttered, and easy to move around in
- A quiet visual style that feels peaceful rather than busy
- A real, dynamic app rather than a static page

## Tech Stack

- **Auth and database:** Supabase (sign-in and saved entries)
- **Frontend:** HTML, CSS, JavaScript

## Getting Started

```bash
# Clone the repository
git clone https://github.com/Summer-nme/selah-space.git
cd selah-space
```

Create a Supabase project, then add your project URL and anon key to the config file:

```js
const SUPABASE_URL = "your-project-url";
const SUPABASE_ANON_KEY = "your-anon-key";
```

Open `index.html` in your browser, or serve the folder locally.
